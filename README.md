# Parse Script

Простой и удобный скрипт для парсинга данных на Node.js с использованием встроенного API `fetch`.

## Требования

- Node.js (версия 18+ с поддержкой встроенного `fetch`)

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/toadstoo/my-parse-script.git
   cd parse-script
   ```

2. Запустите скрипт:
   ```bash
   node parse.js
   ```

## Описание

Скрипт делает GET-запрос к целевому API с настроенными заголовками (`User-Agent`, `Accept`), проверяет тип ответа, выводит часть результатов в консоль и сохраняет полный набор данных в файл `result.json`.
